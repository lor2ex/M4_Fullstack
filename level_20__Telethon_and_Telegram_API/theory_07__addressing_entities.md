### Адресация сущностпей

Во многих методах Telethon нужно указать **получателя сообщения или действия**.

Например:

```python
await client.send_message(target, "Hello")
```

Аргумент `target` указывает, **к какой сущности относится действие**.

В Telethon сущность можно указать **несколькими способами**.

---

#### 1. Username

Самый распространённый способ.

```python
await client.send_message("telegram", "Hello")
```

Работает для:

* пользователей
* публичных групп
* каналов

Потому что у них есть **username**.

---

#### 2. Ссылка

Можно передать ссылку на чат или канал.

```python
await client.send_message("https://t.me/python", "Hello")
```

Telethon автоматически извлечёт username.

---

#### 3. Телефон

Пользователя можно указать по номеру телефона.

```python
await client.send_message("+123456789", "Hello")
```

⚠️ Работает только если пользователь **есть в ваших контактах**.

---

#### 4. ID

Можно использовать числовой идентификатор.

```python
await client.send_message(123456789, "Hello")
```

⚠️ Это работает только если клиент **уже знает эту сущность**.

---

#### 5. Entity

Самый надёжный способ — использовать **объект сущности**.

```python
entity = await client.get_entity("telegram")

await client.send_message(entity, "Hello")
```

Этот способ удобен, если с сущностью нужно работать **несколько раз**.

---

### Что происходит внутри

Независимо от способа адресации, Telethon приводит значение к внутреннему формату Telegram API.

Упрощённо это выглядит так:

```
username / link / id / entity
            ↓
         Entity
            ↓
        InputPeer
            ↓
       Telegram API
```

---

### Итог

В Telethon сущность можно указать несколькими способами:

```
username
link
phone
id
entity
```

Но внутри клиента они всегда преобразуются в специальный объект:

```
InputPeer
```

который используется для отправки запросов в Telegram API.
