### События (`events`)

В Telethon есть система **обработчиков событий (`event handlers`)**,  
которая позволяет реагировать на действия в реальном времени.

Например, новые сообщения, изменение участников чата, реакции и многое другое.

---

### Подключение событий

Сначала импортируем модуль событий:

```python
from telethon import events
```

---

#### 1. Новое сообщение — `NewMessage`

Позволяет реагировать на появление новых сообщений.

Пример:

```python
@client.on(events.NewMessage)
async def handler(event):
    print(event.message.text)
```

Здесь:

* `event` — объект события
* `event.message` — объект `Message`, который можно читать или анализировать
* функция автоматически вызывается при каждом новом сообщении

Можно фильтровать события, например, только из конкретного чата:

```python id="wz8l3k"
@client.on(events.NewMessage(chats="python"))
async def handler(event):
    print(event.message.text)
```

---

#### 2. Действия в чате — `ChatAction`

Позволяет реагировать на действия пользователей:

* кто-то вошёл или вышел из чата
* кто-то пишет сообщение (typing)
* кто-то изменил фотографию или название чата

Пример:

```python
@client.on(events.ChatAction)
async def handler(event):
    print(f"{event.user_id} сделал действие в чате {event.chat_id}")
```

---

#### 3. Особенности использования событий

* События работают **асинхронно**
* Можно **подписаться на несколько обработчиков**
* События удобны для создания ботов, уведомлений или реакций на сообщения в реальном времени
