### Получение сущностей

Чтобы работать с пользователями, группами или каналами, клиент должен сначала получить **сущность (entity)**.

Сущность — это объект Telegram, представляющий:

* `User`
* `Chat`
* `Channel`

Большинство методов Telethon работают именно с сущностями.

Например:

```python
await client.send_message(entity, "Hello")
```

Поэтому первый шаг почти любой программы — **получить нужную сущность**.

---

### Способы получения сущности

#### 1. `get_entity()`

Основной метод для получения сущности.

```python
entity = await client.get_entity("telegram")
```

Метод может принимать разные значения:

```
username
link
phone
id
entity
```

Telethon автоматически определяет тип и возвращает соответствующую сущность.

---

#### 2. `get_dialogs()`

Можно получить сущности из списка диалогов аккаунта.

```python
dialogs = await client.get_dialogs()
```

Пример:

```python
for dialog in dialogs:
    print(dialog.name)
```

Каждый `dialog` содержит:

```python
dialog.entity
```

— сущность соответствующего чата.

---

### Важное ограничение

Если использовать **числовой ID**, клиент должен уже знать эту сущность.

Например, если:

* пользователь есть в ваших диалогах
* вы уже взаимодействовали с каналом
* сущность была получена ранее

Иначе Telegram API не сможет её найти.

---

### Итог

Получение сущности обычно происходит так:

```
username / link / id
        ↓
   get_entity()
        ↓
      Entity
```

После этого сущность можно использовать в других методах клиента.
